# Blog Platform Django App

This repository contains a simple Django-based blog platform application where users can create, edit, and manage blog posts.

## Project Structure

- `blog/` - Django project and app source code
  - `manage.py` - Django management script
  - `blog/` - main Django project package
    - `settings.py` - project settings
    - `urls.py` - URL routing
    - `views.py` - request handlers
    - `models.py` - database models
    - `templates/` - HTML templates
    - `static/` - CSS and JavaScript files
    - `media/` - uploaded images and files

- `bvenv/` - Python virtual environment

## Features

- User registration and login system
- Create, update, and delete blog posts
- Upload blog images
- Responsive and clean user interface
- Admin dashboard for content management
- SQLite database support
